# Phase Definition of Done

For every development phase:
- [ ] Scope matches one phase only.
- [ ] Build passes.
- [ ] Typecheck passes.
- [ ] Relevant tests pass.
- [ ] Keyboard path checked.
- [ ] Mobile layout checked if UI changed.
- [ ] Reduced-motion checked if animation changed.
- [ ] No console errors.
- [ ] Route can be loaded directly if applicable.
- [ ] Acceptance criteria documented in commit/PR notes.
