# User Flows

## First visit
```text
Open site
→ Title screen (very short)
→ Skip / New Game
→ Adventure Room
→ Visual prompt highlights Projects + About
→ User clicks hotspot or direct nav
→ Content opens
→ Quest log updates locally
```

## Recruiter fast path
```text
Open site
→ Skip intro
→ Projects
→ Antero
→ Experience
→ Contact / CV
```

## Direct project link
```text
Open /projects/antero
→ semantic project content visible immediately
→ optional room shell initializes around it
→ close/back returns to Projects/Room
```

## Keyboard path
```text
Tab to Skip
→ Enter
→ Tab through primary hotspots/nav
→ Enter opens section
→ Escape closes dialog/panel
→ focus returns to trigger
```

## Mobile path
```text
Open
→ compact title
→ room image + hotspot cards
→ tap Projects
→ full-screen content route
→ bottom nav
```
