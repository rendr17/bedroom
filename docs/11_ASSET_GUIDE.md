## Production recommendations
- SVG for icons/props.
- AVIF/WebP for final illustrated background if raster art replaces SVG.
- Keep room background under ~500–800 KB where possible.
- Use responsive `<picture>` sizes.
- Lazy-load project screenshots.

## Naming convention
`category-purpose-state.ext`
Examples:
- `icon-projects-active.svg`
- `prop-notebook.svg`
- `poster-better-web.svg`
- `bg-bedroom-night.webp`

## User-specific assets not generated here
A portrait intended to resemble the user should be created only from a current reference image. The included avatar is a neutral placeholder, not a likeness.
