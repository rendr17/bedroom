# MVP Scope

## Must ship
- Intro/title screen with Skip.
- Adventure Room scene.
- Five primary hotspots: About, Projects, Experience, Skills, Contact.
- Persistent direct navigation.
- About content.
- Projects index.
- Four project case studies.
- Experience timeline/list.
- Skills groups.
- Contact links/form surface.
- Quest log marking visited core sections.
- Responsive mobile layout.
- Keyboard navigation.
- Reduced-motion mode.
- SEO metadata and Open Graph baseline.
- Analytics events only if configured.

## Should ship
- Room ambient day/night state based on CSS/theme, not real location.
- Cat interaction.
- One hidden README/floppy easter egg.
- Optional UI sounds toggle.
- 404 page.

## Later
- Mini-game.
- Guestbook.
- Multiple room scenes.
- Theme customizer.
- Achievements.
- Music player.
- More complex inventory.

## Scope rule
If an optional game interaction delays core project content, cut the game interaction first.
